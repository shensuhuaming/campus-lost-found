## 1 ER 图（概念结构设计）

> **图例**：矩形＝实体，菱形＝联系，椭圆＝属性，双矩形＝弱实体，双菱形＝识别联系，下划线＝主键，连线上的 1 / N / M 为联系基数。
>
> **可编辑源文件**：[ER图.drawio](ER图.drawio)。用浏览器打开 [app.diagrams.net](https://app.diagrams.net) → 打开该文件即可编辑 → 导出 PNG 插入课程报告。

**说明**：

1. 参照参考图样式，**认领、留言为联系（菱形）且带属性**：认领联系（M:N）的属性为细节描述、申请时间、状态、核验回复、管理员编号；留言联系（M:N，一个用户可留言多条信息、一条信息可有多条留言）的属性为内容、留言时间；
2. **图片为弱实体**（双矩形），依赖失物信息存在；包含为识别联系（双菱形）；
3. **审核联系**由角色为管理员的用户执行，管理员与学生合并建模为"用户"实体，通过"角色"属性区分（与参考图中销售员、派送员分开建模不同，本系统采用单表设计）；
4. 认领表与用户表存在两条外键联系——"发起"（applicant_id）与"核验"（admin_id）。
5. **图示为关键属性示意**：为控制图幅，`用户.用户编号`（主键）、`失物信息.联系方式 / 驳回理由 / 发布时间 / 更新时间`、`站内消息.发送人编号`（0 表示系统）等字段未在图中画出；站内消息实际存在"接收"（to_user_id）与"发送"（from_user_id）两条指向用户的联系。完整属性以第 2 节关系模式与《详细设计》5.x 为准。

## 2 关系模式（逻辑结构设计）

ER 图向关系模式转换遵循以下规则：

1. 每个实体转换为一个关系模式；弱实体与识别联系合并（图片并入 item_image）；
2. 1:N 联系并入 N 端：发布 → lost_item 的 user_id，属于 → lost_item 的 category_id，接收 → message 的 to_user_id，审核 → lost_item 的 audit_status；
3. M:N 联系转换为独立关系模式："认领"→ claim、"留言"→ comment，联系属性成为表的属性，联系两端实体的主键作为外键。

下划线加粗为主键，*斜体*为外键。

1. 用户表：user(**用户编号**, 学号, 密码, 昵称, 联系方式, 角色, 状态, 注册时间)
2. 分类表：category(**分类编号**, 分类名称, 排序号, 创建时间)
3. 物品信息表：lost_item(**物品编号**, 类型, 标题, 描述, *分类编号*, *发布者编号*, 丢失/拾取时间, 地点, 联系方式, 审核状态, 驳回理由, 物品状态, 发布时间, 更新时间)
4. 图片表：item_image(**图片编号**, *物品编号*, 图片路径, 排序号)
5. 认领申请表：claim(**申请编号**, *物品编号*, *申请人编号*, 细节描述, 状态, 核验回复, *管理员编号*, 申请时间)
6. 留言表：comment(**留言编号**, *物品编号*, *用户编号*, 内容, 留言时间)
7. 站内消息表：message(**消息编号**, *接收人编号*, *发送人编号*, 消息类型, 内容, 关联物品编号, 是否已读, 发送时间)

## 3 完整性约束

### 3.1 实体完整性

所有表的主键非空且唯一。

### 3.2 参照完整性（外键约束）

| 表 | 外键 | 引用 |
|---|---|---|
| lost_item | 分类编号 | category.分类编号 |
| lost_item | 发布者编号 | user.用户编号 |
| item_image | 物品编号 | lost_item.物品编号（级联删除：删除物品时同步删除图片记录） |
| claim | 物品编号 | lost_item.物品编号 |
| claim | 申请人编号 | user.用户编号 |
| claim | 管理员编号 | user.用户编号 |
| comment | 物品编号 | lost_item.物品编号 |
| comment | 用户编号 | user.用户编号 |
| message | 接收人编号 | user.用户编号 |

### 3.3 用户自定义完整性

| 字段 | 约束 |
|---|---|
| lost_item.audit_status | 取值：0 待审核 / 1 通过 / 2 驳回 |
| lost_item.item_status | 取值：0 进行中 / 1 处理中 / 2 已完成 / 3 已关闭 |
| claim.status | 取值：0 待核验 / 1 通过 / 2 拒绝 |
| user.role | 取值：0 学生 / 1 管理员 |
| user.status | 取值：0 正常 / 1 禁用 |
| 图片数量 | 每个物品 ≤3 张（应用层校验） |
| 文本长度 | 标题 ≤30 字、描述 ≤500 字、认领描述 ≤300 字（应用层校验） |

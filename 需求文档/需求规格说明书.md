## 1 引言

### 1.1 编写目的

本文档描述校园失物招领系统的功能需求与非功能需求，明确系统的目标、范围与验收标准，作为后续概要设计、详细设计、编码实现、系统测试和项目验收的统一依据。

预期读者：项目开发团队全体成员、指导教师及评审人员。

### 1.2 项目背景

校园内师生物品遗失与拾取事件频繁发生。目前主要依赖公告栏、社交媒体群等方式发布信息，存在以下问题：

1. 信息分散，无法集中检索；
2. 缺乏统一的分类管理，查找困难；
3. 认领过程缺乏身份核验，存在冒领风险；
4. 信息状态（是否已归还）无法跟踪，失主需反复询问。

为此，本项目开发一个基于 Web 的校园失物招领系统，实现失物信息发布、检索、认领归还全流程线上管理。

### 1.3 术语定义

| 术语 | 定义 |
|---|---|
| 寻物启事 | 失主发布的寻找遗失物品的信息 |
| 拾物招领 | 拾到者发布的寻找失主的信息 |
| 认领申请 | 用户对拾物招领信息发起的领取请求 |
| 物品状态 | 信息在系统中的生命周期状态，见 3.4 节 |
| 归还率 | 已归还物品数 ÷ 拾物招领信息总数 |
| 管理员 | 负责信息审核、认领核验、用户与分类管理、数据统计的系统角色 |

## 2 系统概述

### 2.1 系统目标

建设一个覆盖"发布—检索—认领—归还"全流程的校园失物招领 Web 系统，具体目标：

1. 失主与拾到者均可便捷发布带图片的失物信息；
2. 用户可按分类、类型、关键词快速检索信息；
3. 认领需经身份核验，防止冒领；
4. 物品状态全程可跟踪，形成闭环；
5. 管理员可审核信息、统计数据，掌握整体情况。

### 2.2 用户角色

| 角色 | 职责 |
|---|---|
| 学生（注册用户） | 注册登录、发布寻物/拾物信息、浏览检索、留言、发起认领申请、接收站内消息 |
| 管理员 | 信息审核、认领核验、分类管理、用户管理、数据统计 |
| 游客（未登录） | 仅可浏览已通过审核的信息，不可发布、留言、认领 |

### 2.3 运行环境

| 类别 | 环境 |
|---|---|
| 部署方式 | 本机运行（课程演示） |
| 后端 | JDK 17、Spring Boot 3.x、MySQL 8.x |
| 前端 | Node.js 18+、Vue 3、Element Plus |
| 浏览器 | Chrome / Edge 最新版 |

### 2.4 功能总览

| 模块 | 功能点 | 优先级 |
|---|---|---|
| 用户模块 | 注册、登录/退出、个人资料、修改密码 | 高 |
| 失物信息模块 | 发布（含图片）、编辑、下架、审核 | 高 |
| 浏览检索模块 | 列表浏览、分类/类型筛选、关键词搜索、详情 | 高 |

| 管理后台模块 | 分类管理、用户管理、数据统计 | 中 |

## 3 功能需求

### 3.1 用户模块

#### FR-01 学生注册

- **描述**：学生填写学号、密码、昵称、联系方式完成注册。
- **输入**：学号（必填，唯一）、密码（6~20 位）、确认密码、昵称（必填）、联系方式（手机号或 QQ/微信）。
- **处理**：校验学号未注册；两次密码一致；密码加密存储（BCrypt）。
- **输出**：注册成功提示并跳转登录页；失败给出明确原因（如"该学号已注册"）。

#### FR-02 登录与退出

- **描述**：用户使用学号+密码登录；登录后签发 JWT 令牌，前端后续请求携带令牌。
- **输入**：学号、密码。
- **处理**：校验账号存在、密码正确、账号未被禁用。
- **输出**：登录成功进入首页；失败提示"学号或密码错误"；退出后清除本地令牌。

#### FR-03 个人中心

- **描述**：用户查看与修改个人资料、修改密码。
- **输出页面**：我的发布（列表+状态）、我的认领申请（列表+结果）、我的留言、修改资料、修改密码。

#### FR-04 账号管理（管理员）

- **描述**：管理员可禁用/启用违规学生账号；被禁用账号无法登录。

### 3.2 失物信息模块

#### FR-05 发布信息

- **描述**：登录用户发布寻物启事或拾物招领。
- **输入**：类型（寻物/拾物）、标题（必填，≤30 字）、分类（6 类之一）、物品描述（≤500 字）、丢失/拾取时间与地点、联系方式、图片（最多 3 张，jpg/png，单张 ≤2MB）。
- **处理**：发布后默认进入"待审核"状态，管理员审核通过后前台可见。
- **输出**：发布成功提示；审核结果通过站内消息通知发布者。

#### FR-06 编辑与下架

- **描述**：发布者可编辑自己发布的物品信息；可主动下架（关闭）自己的信息；管理员可下架任何违规信息并填写理由。

#### FR-07 图片上传

- **描述**：上传物品照片便于辨认，最多 3 张，按上传顺序展示，详情页可点击放大。

### 3.3 浏览与检索模块

#### FR-08 列表浏览

- **描述**：首页展示已审核通过的物品信息列表，按发布时间倒序分页展示（每页 12 条），每条显示封面图、标题、分类、类型标签、发布时间、状态标签。

#### FR-09 分类与类型筛选

- **描述**：用户可按 6 个分类（证件、电子产品、钥匙、书籍、衣物、其他）和类型（全部/寻物/拾物）组合筛选。

#### FR-10 关键词搜索

- **描述**：按关键词对标题与描述做模糊匹配，结果按相关度与时间排序。

#### FR-11 详情页

- **描述**：展示完整图文信息、联系方式；拾物信息提供"认领"按钮；底部为留言区（需登录）。

### 3.4 认领归还模块

#### FR-12 物品状态流转

```
待审核 →(管理员通过)→ 进行中 →(有人认领/已联系)→ 处理中 →(管理员确认)→ 已完成
   ↓(驳回)              ↓(发布者或管理员关闭)        ↓(超时或放弃 → 退回进行中)
  已驳回               已关闭
```

- 进行中：寻物 = 寻物中；拾物 = 待认领
- 处理中：拾物 = 认领申请待核验；寻物 = 已联系到拾到者
- 已完成：拾物 = 已归还；寻物 = 已找回

#### FR-13 认领申请

- **描述**：登录用户对拾物信息发起认领。
- **输入**：物品细节描述（颜色、品牌、型号、内含物等，必填，≤300 字），用于核验是否为真正失主。
- **处理**：同一用户对同一物品仅可申请一次；申请后物品进入"处理中"。
- **输出**：申请成功提示；核验结果通过站内消息通知申请人。

#### FR-14 管理员核验

- **描述**：管理员查看认领申请及物品详情，判断申请人是否为失主。
- **处理**：通过 → 物品状态置为"已归还"，该物品其余认领申请自动拒绝；不通过 → 填写拒绝理由。
- **输出**：结果通知申请人。

#### FR-15 关闭信息

- **描述**：寻物信息已找回或拾物信息长期无人认领时，由发布者或管理员关闭，状态置"已关闭"。

### 3.5 留言与消息模块

#### FR-16 留言

- **描述**：登录用户可在物品详情页留言询问细节；发布者收到站内消息提醒；发布者与管理员可删除不当留言。

#### FR-17 站内消息

- **描述**：系统在以下场景发送站内消息：信息审核通过/驳回、留言提醒、认领申请收到提醒（发给发布者）、认领结果通知（发给申请人）。消息支持已读/未读标记，未读消息在导航栏显示红点数量。

### 3.6 管理后台模块

#### FR-18 信息审核

- **描述**：管理员查看待审核信息列表，逐条通过或驳回（填写理由）。

#### FR-19 分类管理

- **描述**：管理员可新增、重命名、删除分类；分类下存在物品时禁止删除；支持调整排序。

#### FR-20 数据统计

- **描述**：后台首页以图表展示：物品总量（分类型/分状态）、分类占比饼图、近 30 天新增趋势折线图、归还率指标卡。

## 4 非功能需求

| 编号 | 类别 | 要求 |
|---|---|---|
| NFR-01 | 性能 | 常规查询响应 ≤2 秒；支持 20 人同时在线（演示环境） |
| NFR-02 | 安全 | 密码 BCrypt 加密；JWT 鉴权；管理接口权限校验；防 SQL 注入、XSS；图片类型与大小校验 |
| NFR-03 | 界面 | 统一使用 Element Plus 组件风格，界面简洁、核心操作不超过 3 次点击 |
| NFR-04 | 兼容性 | 支持 Chrome、Edge 最新版本 |
| NFR-05 | 可维护性 | 前后端分离、代码分层清晰（Controller/Service/Mapper）、关键逻辑有注释 |

## 5 数据需求

### 5.1 实体关系概述

用户发布物品信息（1:N）；物品属于一个分类（N:1）；一个物品可有多张图片（1:N）、多条留言（1:N）、多个认领申请（1:N）；用户接收多条站内消息（1:N）。

### 5.2 数据字典

| 表名 | 说明 | 主要字段 |
|---|---|---|
| user | 用户表 | id、student_no（学号，唯一）、password（密文）、nickname、phone、role（0 学生/1 管理员）、status（0 正常/1 禁用）、created_at |
| category | 分类表 | id、name、sort、created_at |
| lost_item | 物品信息表 | id、type（0 寻物/1 拾物）、title、description、category_id、user_id、happen_time、happen_place、contact、audit_status（0 待审核/1 通过/2 驳回）、reject_reason、item_status（0 进行中/1 处理中/2 已完成/3 已关闭）、created_at、updated_at |
| item_image | 图片表 | id、item_id、url、sort |
| claim | 认领申请表 | id、item_id、applicant_id、detail_desc、status（0 待核验/1 通过/2 拒绝）、reply、admin_id、created_at |
| comment | 留言表 | id、item_id、user_id、content、created_at |
| message | 站内消息表 | id、to_user_id、from_user_id（0 表示系统）、type、content、item_id、is_read、created_at |

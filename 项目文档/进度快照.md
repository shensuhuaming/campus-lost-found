## 四、本机已知坑（务必记住）

| 坑 | 绕过方式 |
|---|---|
| Maven 本地仓库不可写（settings.xml 指向只读 `mvn_repo`） | 本机构建加 `-Dmaven.repo.local=%USERPROFILE%\.m2\repository`；IDEA 里把 Local repository 改到 `C:\Users\<你>\.m2\repository`。容器内构建已改用 `backend/maven-settings.xml`（阿里云镜像） |
| 目录名含中文导致 compose 项目名为空 | 已在 `docker-compose.yml` 写死 `name: clf` |
| Docker Hub 直连超时 | 用 `docker.m.daocloud.io` 拉取后 `docker tag` 回官方名（`docker.xuanyuan.me` 有免费额度限制） |
| `vite build` 报 esbuild 临时文件 `Access is denied` | 构建前把 `TEMP`/`TMP` 指到项目内 `.tmp` 目录 |
| 工程目录含中文导致 JaCoCo 无数据 | Windows 下 surefire 经 `cmd.exe` 传参时非 ASCII 路径变成 `?`，agent 写不出 exec（报 `missing execution data file`）。已在 `pom.xml` 把 `destFile`/`dataFile` 指到 `${java.io.tmpdir}`（纯 ASCII） |
| Docker Desktop 不随开机启动 | 需要先手动启动 Docker Desktop，等引擎就绪（约 15 秒） |
| 全局 `http.sslverify=false` | 建议在 GitHub 推送前临时取消，或至少知晓风险 |

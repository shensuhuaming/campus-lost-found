## 四、本机已知坑（务必记住）

| 坑 | 绕过方式 |
|---|---|
| Maven 本地仓库不可写（settings.xml 指向只读 `mvn_repo`） | 构建时加 `-Dmaven.repo.local=%USERPROFILE%\.m2\repository`；IDEA 里把 Local repository 改到 `C:\Users\<你>\.m2\repository` |
| 目录名含中文导致 compose 项目名为空 | 已在 `docker-compose.yml` 写死 `name: clf` |
| Docker Hub 直连超时 | 用镜像加速器拉取后 `docker tag` 回官方名 |
| `vite build` 报 esbuild 临时文件 `Access is denied` | 构建前把 `TEMP`/`TMP` 指到项目内 `.tmp` 目录 |
| 全局 `http.sslverify=false` | 建议在 GitHub 推送前临时取消，或至少知晓风险 |

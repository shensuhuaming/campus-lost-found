# 编码与单元测试 · 交付清单（v1.0.0）

> 用途：把"编码 + 单元测试"这一棒完整交给开发小组与集成测试同学。
> 每一项都写明**位置、给谁用、怎么验证**；§5 是尚未完成的缺口，不藏问题。

## 1 一句话总览

| 交付维度 | 结论 |
|---|---|
| 代码 | 前后端 + 数据库脚本 + 容器编排，`docker compose --profile full up -d --build` 一键起全栈 |
| 质量 | 后端 **138 个单元测试全绿**；前端 `npm run build` 通过；CI 每次 push 自动跑 |
| 文档 | README / CHANGELOG / CONTRIBUTING / 使用说明书 / 11 篇迭代记录 / 进度快照 / 审查意见 |
| 测试资产 | 单测 138 个 + JaCoCo 覆盖率 + **19 步端到端冒烟脚本** `scripts/smoke-test.ps1` |
| 环境 | `docker-compose.yml` + `.env.example` + 镜像构建文件 + DDL 与分类种子 |
| 过程痕迹 | Git 分支 + `--no-ff` 合并 + tag `v1.0.0`，每次迭代一份记录 |

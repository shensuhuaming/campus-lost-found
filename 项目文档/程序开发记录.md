## 1 开发日志

### 2026-11-12｜迭代 00 环境基座

- **开发内容**：Docker Compose 三服务（mysql 3307 / backend 8080 / frontend 80）；后端骨架（Spring Boot 3.5.9 + MyBatis-Plus + JWT 依赖）；前端 Vite 脚手架；健康检查接口；GitHub 仓库与首次推送；建立"CHANGELOG + 迭代记录 + PR 模板 + 提交规范"留痕机制。
- **问题与解决**：
  1. `docker compose` 报 "project name must not be empty" —— 仓库路径含中文，改为在 compose 里显式 `name: clf`；
  2. Docker Hub 拉镜像超时 —— 用 `docker.m.daocloud.io` 镜像拉取后 `docker tag` 回官方名；
  3. JaCoCo 在中文路径下找不到 exec 文件 —— `destFile/dataFile` 改到 `${java.io.tmpdir}`；
  4. Maven 本地仓库只读 —— 统一加 `-Dmaven.repo.local=%USERPROFILE%\.m2\repository`。
- **验证**：`docker compose --profile full up -d --build` → 首页自检"后端 UP / 数据库 UP"；`mvn test` 通过。
- **提交**：`cc21d9a`（环境基座）、`203c3f6`（打通数据库与全栈验证）、`317fcbd`（JaCoCo 修复）、`690104b`（留痕机制）。

### 2026-11-19｜迭代 05 用户认证 U1.1~U1.3

- **开发内容**：注册/登录/退出；JWT（HS256，12h）；拦截器（白名单 + 禁用校验）；`Result`/`ResultCode`/异常处理；管理员初始化。
- **问题与解决**：
  1. 纯 Mockito 测试报 `MybatisPlus can not find lambda cache` —— 测试静态块初始化 `TableInfoHelper`；
  2. `@WebMvcTest` 切片返回空响应 —— mock 的 `JwtInterceptor.preHandle` 默认 false，改为 `thenReturn(true)`。
- **验证**：`mvn test` 24 个用例通过；curl 跑通注册/登录/退出。
- **提交**：`78f7d22`（merge）。

### 2026-11-19｜迭代 06 个人中心与前端登录 U1.4~U1.6

- **开发内容**：资料/改密/我的三个列表（批量补齐，无 N+1）；前端登录页、个人中心、路由守卫、axios 拦截器。
- **问题与解决**：前端发送的 `happenTime` 与后端时间格式不一致，新增 `JacksonConfig` 统一 `yyyy-MM-dd HH:mm:ss` 并兼容 ISO。
- **验证**：42 个用例通过；页面登录→个人中心→改密全流程可用。
- **提交**：`054b878`（merge）。

### 2026-11-19｜迭代 07 失物信息 M2 + 浏览检索 M3

- **开发内容**：发布（≤3 图，三重校验）、上传（类型/大小/魔数）、编辑（重审）、关闭（管理员必填理由，自动取消待核验认领）、寻物推进；列表/筛选/搜索（标题优先）/详情（脱敏、留言前 10、我的认领状态）；公开分类；首页/详情/发布三个页面。
- **问题与解决**：
  1. 搜索带中文直接拼 URL 返回 400 —— 测试脚本改用 `--data-urlencode`；
  2. 早期演示数据的 `happen_place` 乱码 —— 用 UTF-8 SQL 文件重刷（`docker exec -i ... < file.sql`）。
- **验证**：73 个用例通过；curl 跑通上传→发布→审核（SQL 置过审）→列表→搜索→详情→编辑→关闭→推进。
- **提交**：`020162a`（merge）。

### 2026-11-19｜迭代 08 认领与核验 M4

- **开发内容**：发起认领（四类前置校验 + 唯一索引兜底）、管理员核验列表（三表关联）、核验通过（单事务 + 其余申请自动拒绝 + 三方通知）、核验拒绝（无其他申请时回退物品状态）；详情页认领弹窗、`/admin/claims` 页面。
- **问题与解决**：核验通过时"物品条件更新失败"必须整体回滚 —— 用 `@Transactional(rollbackFor=Exception.class)` + 先更新物品再更新申请，失败抛异常。
- **验证**：93 个用例通过；curl 跑通认领→重复 3003→越权 2002→核验通过→拒绝→回退。
- **提交**：`0152bfc`（merge）。

### 2026-11-19｜迭代 09 留言与站内消息 M5

- **开发内容**：发表/删除留言（通知发布者，自己留言不打扰）、消息列表（只看自己、可筛选）、已读（幂等）、未读数；详情页留言输入、`/messages` 消息中心、导航未读角标（60 秒轮询）。
- **问题与解决**：`MessageService` 需要携带发送人（留言提醒显示留言人昵称）—— 增加 `push(to, from, ...)` 重载，保留原签名兼容既有调用。
- **验证**：112 个用例通过；curl 跑通留言→消息→已读→未读数 9→8→越权 2002。
- **提交**：`7c4dce5`（merge）。

### 2026-11-19｜迭代 10 管理后台 M6

- **开发内容**：待审列表 + 审核（条件更新、驳回必填理由、通知）、分类增删改（引用保护）、用户列表与启用禁用、统计（四项指标 + 分类分布 + 30 天趋势）；`/admin` 四页签 + ECharts 图表（独立分包）。
- **问题与解决**：
  1. 统计趋势需要"缺日补零" —— SQL 只返回有数据的日期，应用层按区间补齐；
  2. 前端主包超过 1200KB 警告 —— `manualChunks` 把 ECharts 拆出。
- **验证**：138 个用例通过；curl 跑通审核→分类 5001/5002→禁用 1004→统计；全量测试曾出现 1 次偶发失败，随后连续多次运行均全绿（已在迭代记录登记）。
- **提交**：`316f9e7`（merge，tag `v1.0.0`）。

## 4 关键决策记录

| # | 决策 | 结论 | 依据 / 影响 |
|---|---|---|---|
| 1 | 成功码用 0 还是 200 | **200** | 对齐《API 规格》1.2，前端同步 |
| 2 | 消息何时发送 | **事务提交后（afterCommit）** | 避免业务回滚仍通知 |

| 7 | 编辑后是否重审 | **重审** | 防绕过审核 |
| 8 | 管理员关闭为何必填理由 | **审计需要** | 评审 P0-3 |

## 3 关键实现点

1. **成功码 200**：`Result.ok()` 固定 200，`ResultCode` 携带 HTTP 状态，`GlobalExceptionHandler` 统一映射（对齐 API 规格 1.2/1.4）；
2. **防账号枚举**：账号不存在与密码错误都返回 1003；
3. **禁用即时生效**：拦截器每次查库校验 `status`，不只看 token（详细设计 8.1）；
4. **ThreadLocal 清理**：`afterCompletion` 中 `SecurityUtil.clear()`，避免线程复用串号；
5. **并发注册兜底**：唯一索引冲突（`DuplicateKeyException`）同样转 1002；
6. **密码安全**：BCrypt cost=10，任何 VO 都不含 password；JWT 只放 `uid`、`role`。
